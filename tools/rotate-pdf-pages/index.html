FAQ

Is the rotation saved in the file?

Yes. The page rotation setting is written into the PDF, so every viewer shows it the same way.

Can I rotate only some pages?

Yes. Type the pages, for example "2-4, 9", or leave "all".

What if a page was already rotated?

The new rotation is added to the existing one.
