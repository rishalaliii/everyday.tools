FAQ

Is my data sent anywhere?

No. The code is generated in your browser; nothing is uploaded.

Do these QR codes expire?

No. They are static: the content is stored in the code itself, so they work as long as the link or data stays valid.

Which error-correction level should I pick?

M suits most uses. Choose H if the code may get dirty or have a logo placed over it; higher levels make denser codes.

Will the Wi-Fi code work on every phone?

Recent iPhone and Android cameras read it. Always test-scan before printing.
