FAQ

Can I choose the page order?

Yes. Pages come out in the order you type them, so "5, 1-2" gives page 5 first. Typing a page twice repeats it.

What if I type a page that does not exist?

You will see an error naming the page and the valid range; nothing is created.

What is not kept?

Bookmarks, form fields and document-level tags may not be carried over; page content, images, text and links are.
