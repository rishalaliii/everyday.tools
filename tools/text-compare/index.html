Text Compare (Diff)

Compare two texts line by line and see what changed. Your text never leaves this page.

FAQ

How does it compare?

Line by line, using a longest-common-subsequence diff. Changes inside a line show as one removed plus one added line.

Is there a size limit?

About 2,000 lines per side, to keep your browser responsive.
