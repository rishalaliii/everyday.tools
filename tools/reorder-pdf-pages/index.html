    FAQ

    How do I reorder?

    Use ↑ and ↓ on each page, delete with ✕, or type a full order like "3, 1, 2, 4" and press Apply order.

    Can I delete pages here?

    Yes. Pages you remove are left out of the new file.

    Is there a page preview?

    Not yet. The list shows original page numbers, so check the original in a PDF viewer if you are unsure which page is which.
